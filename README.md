# dublin-extensions-spatial-analysis
### GEOG41160 - Assignment 2:Python for GIS
Team: UCD-GEOG41160-2026-Team-1

This repository contains the Python scripts, spatial datasets, and analysis outputs for GEOG41160 Assignment 2:Python for GIS at University College Dublin.The project focuses on spatial analysis of Dublin's electoral divisions(EDs),examining the geographical distribution and density of extensions using Python and GIS techniques.The analysis is organised into three questions, including extension density calculations and globalspatial clustering.

## Repository Structure
The repository is organised as follows:
data/- contains the input spatial datasets required for the analysis.
scripts/-contains the Python scripts for each assignment question.
        Q1_ExtensionDensity.py - Extension density analysis
        Q2_GlobalMoran.py- Global spatial autocorrection analysis.
        Q3_LISA_Gistar.py-Local spatial autocorrection analysis
outputs/- stores generated maps, figures,spatial datasets, and statistical results.
README.md- Provides project documentation and instructions.
SPRINT_LOG.md-Records team progress, contributions and updates.  

## Coordinate Reference System(CRS)
CRS Used:EPSG:2157 -Irish Transverse Mercator(ITM)
Purpose:A projevted CRS is used because it provides accurate distance and area measurements in metres.
Area Calculations:ITM coordinates are measured in metres, allowing Electoral Division Areas to be calculated accurately and converted to square kilometres.
Comparison with Web Mercator:Web Mercator (EPSG:3857) distorts areas and distances making it less suitable for accurate area measurements in Dublin. ITM provides more reliable results.

## Script Execution Order
The python scripts should be executed in the following order:
1.Q1_ExtensionDensity.py-  calculates extension density for Dublin's Electoral Divisions and saves the resulting spatial dataset.
2.Q2_GlobalMoran.py -Uses the output from Question 1 to examine global spatial autocorrelation using Moran's 1.
3.Q3_LISA_GIStar.py - Uses the extension density results to investigate local spatial clustering and identify spatial patterns.
Question 1 must be completed before running Questions 2 and 3 because both scripts depend on the extension density dataset generated by Question 1.
